# Casino Cards - Mayor o Menor

Juego de cartas creado en Python con Pygame.

## Características

- Menú interactivo
- Juego multijugador de 2 a 4 jugadores
- Jugadores humanos o PC
- Selección de rondas
- Nombres personalizados
- Animación al voltear cartas
- Sonidos de acierto y fallo
- Diseño estilo casino
